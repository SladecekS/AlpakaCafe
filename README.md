# AlpakaCafe
Veb aplikacija za rezervaciju termina u Alpaka kafiću. Sistem omogućava korisnicima pregled dostupnih termina, rezervaciju i otkazivanje poseta, kao i pregled galerije alpaka. Administratorima omogućava upravljanje terminima, rezervacijama i fotografijama alpaka. Projekat je razvijen korišćenjem ASP.NET Core MVC tehnologije i n-tier arhitekture.
